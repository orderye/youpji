## 分层与依赖方向

```text
前端 (Flutter / Next / Admin)
  → HTTP API (Axum, /api/v1/*)
    → 领域 crates (auth / user / attraction / … / route / itinerary / ai)
      → PostgreSQL(PostGIS + pgvector) / Redis / AI Gateway / 外部地图与天气
```

两条不可违反的方向性规则：

- 领域 crates **不得**依赖 HTTP 框架细节，handler 一律放 api 层。
- Worker / Scheduler 与 API 共享 crates，**不复制业务逻辑**。

## `scripts/` —— 数据管线

V0.1 把「AI 不决定事实」落成一条可重跑的 Node 流水线。**入口在仓库根，不在 `youpji/`**。

| 脚本 | 职责 |
|---|---|
| `seed.mjs` | 向数据库导入 `youpji/data/seed/seed.sql` |
| `import-gov-registry.mjs` | 解析贵州省人民政府「景点名录」，生成 `gov-registry.json`（**票价权威来源**） |
| `import-attractions.mjs` | 事实校验 + 生成 seed SQL 片段（景区表 + 营业时段表） |
| `geocode.mjs` | 坐标补全：高德 POI 优先，Nominatim 回退（WGS-84 需折算） |
| `build-attraction-seed.mjs` | 主流水线编排（见下） |

主流水线阶段：

```text
合并去重 → 坐标补全 → 坐标系归一化 → 事实校验 → 坐标关卡 → 生成 SQL
```

### 三道强制关卡

1. **事实校验** —— `verified` 必须有 `source_url` 且 `confidence ≥ 0.7`；
   票价/开放时间缺失一律落 `pending`/`unverified`，不允许用估算值冒充。
2. **坐标系归一化** —— OSM/Nominatim 返回 WGS-84，高德返回 GCJ-02，境内相差 300–600 m。
   流水线自动折算，原值与偏移量写入 `coord_note` 留痕。**坐标系无法判定的记录不入库。**
3. **坐标完整性** —— 无坐标不入库。坐标是路线引擎召回与距离计算的硬依赖。

### 常用命令

```bash
npm run attractions:check              # 试跑，只出报告
npm run attractions:build              # 校验并生成 seed SQL
AMAP_KEY=xxx npm run attractions:build # 高德优先取点
GEOCODE_LIMIT=60 npm run attractions:build   # 每轮补 60 条坐标
GEOCODE_LIMIT=0 npm run attractions:build    # 只用已有坐标
```

后端 Rust 代码总量约 **7000 行**。

### 迁移约定

- 已合并的迁移**不改内容，只追加**。
- 每条可变旅游事实必须带：`source_type`、`source_url`、`source_time`、`last_verified`、
  `verification_status`、`confidence`。
- 来源分级：一级（景区/政府/官方交通）> 二级（地图/酒店/餐饮平台）> 三级（社区/攻略）>
  四级（AI 生成）。重要数据以一级来源为准。
- `fact_status_check()` 是数据库层兜底：二级来源或 `confidence < 0.7` 不得标 `verified`。


## `youpji/deploy/` —— 编排

`docker-compose.yml` 合并为单文件，服务名对齐 `DESIGN.md §12`：
`postgres redis api worker scheduler web admin`。

`web` / `admin` 置于 profile，默认不启动（前端产物目录 `frontend/out`、`admin/dist`
尚未生成），需要时显式开启：

```bash
cd youpji/deploy
docker compose up -d
docker compose --profile web --profile admin up -d
```

数据库镜像需 PostGIS + pgvector；无 PostGIS 的本地环境由 CI 兜底校验。
